# Tradewell live demos

**Tradewell 2.0.1 by Prosper Technologies** is a WordPress block theme for home-service businesses.

These free demos build an isolated WordPress site in your browser using WordPress Playground. Load time depends on your browser and connection. Changes stay in your own Playground; this is not conventional hosted WordPress. Do not enter real customer information. Email delivery is not available in the browser demo.

## Included plugin

Tradewell Leads is an optional companion plugin. The theme uses TGM Plugin Activation to download it from this repository after the site administrator chooses to install it. The ThemeForest main download also includes a manual-install copy.
